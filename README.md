# Easy Treatment

Easy Treatment is a responsive healthcare website developed using HTML, CSS, and JavaScript. The project provides a modern user interface where users can browse doctors, search specialists, book appointments, and contact healthcare services.

## Features
- Responsive Design
- Doctor Search
- Appointment Booking Form
- Login & Signup Pages
- Services Section
- Testimonials
- About & Contact Sections
- Password Show/Hide
- Form Validation

## Technologies Used
- HTML5
- CSS3
- JavaScript
